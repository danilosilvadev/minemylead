Instale o app.

Obrigado pela compra. Escolha a sua plataforma abaixo.

Windows

Este aparelho

MineMyLead-windows-x64-setup.exe

  1. Baixe o instalador e execute.
  2. Se o SmartScreen aparecer, escolha Mais informações e depois Executar assim mesmo.
Baixar para Windows

macOS

Este aparelho

MineMyLead-macos.dmg

  1. Baixe a imagem de disco e abra.
  2. Se o macOS bloquear o app, clique com o botão direito e escolha Abrir.
Baixar para macOS

Linux

Este aparelho

MineMyLead-linux-x64.AppImage

  1. Baixe o AppImage.
  2. Marque como executável: chmod +x MineMyLead-linux-x64.AppImage
  3. Rode o arquivo.
Baixar para Linux

Android

Este aparelho

MineMyLead-android.apk

  1. Baixe o APK e abra.
  2. Se o Android bloquear a instalação, permita apps desconhecidos para esta fonte e continue.
Baixar para Android

iPhone

Este aparelho

MineMyLead-ios-unsigned.ipa

  1. Baixe o IPA não assinado num computador.
  2. Instale por sideload com AltStore ou Sideloadly.
Baixar para iPhone

Pacote do nicho

Como importar o seu pack.zip

  1. Guarde o pack.zip que chega para o seu nicho.
  2. Abra o MineMyLead e importe esse arquivo: arraste o pack.zip para a janela, ou escolha Importar e selecione o arquivo.
  3. Os leads ficam neste aparelho. O app não envia o pacote para lugar nenhum.
